## Die vier teuren Punkte für dieses Layout
1. 2.4.11 Fokus nicht verdeckt: `html{scroll-padding-top: Header+20px; scroll-padding-bottom: Bottom-Bar+20px}`, scroll-margin auf Ankern. https://www.w3.org/WAI/WCAG22/Techniques/css/C43
2. 1.4.10 Reflow bei 320 px / 1.4.12 Text-Spacing: Sticky-Header und Bottom-Bar bei sehr kleinen Viewports (max-height 500 px) auf static schalten; kein max-height+overflow:hidden auf Text. Zoom 400 % ohne horizontales Scrollen. https://www.w3.org/WAI/WCAG22/Understanding/reflow.html
3. 2.5.8 Zielgröße ≥ 24×24 px, Praxisziel 44×44 (Bottom-Bar, Menü, Telefon). https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
4. 3.2.6 Konsistente Hilfe: Telefon/E-Mail/Kontakt auf allen Seiten in derselben relativen DOM-Reihenfolge. https://www.w3.org/WAI/WCAG22/Understanding/consistent-help.html

## Kontrast
- Text 4,5:1; großer Text (≥ 24 px normal oder ≥ 18,66 px fett) 3:1; UI-Komponenten, Fokusring, Icons 3:1. Nicht runden. Text auf Fotos an der kontrastärmsten Stelle messen → Scrim.

## Navigation
- Skip-Link erstes fokussierbares Element, Ziel `<main id tabindex="-1">`. Ein `<main>`, `<nav aria-label>`, eine h1 je Seite, lang="de", eindeutiger title.
- Menü-Button: `aria-expanded`, `aria-controls`; KEIN role="menu". Overlay: Fokus hinein, Rest `inert`, Escape schließt und Fokus zurück auf Button.
- Fokusring ≥ 2 px, 3:1 (Ziel 2.4.13: 3px solid, offset 2px). Links nicht nur durch Farbe.

## Bilder / Bewegung / FAQ / Karte
- Dekorativ alt="", informativ kurz, Text nicht im Bild einbrennen (1.4.5).
- Kein Autoplay > 5 s (2.2.2). prefers-reduced-motion: Animationen und smooth scroll aus. Kein Parallax für Ältere.
- details/summary ok für FAQ; Überschrift in summary inkonsistent in Safari → Frage als reiner summary-Text; kein max-height.
- Google-Maps-iframe: title Pflicht, Adresse als Text daneben, Routen-Link, Tastatur-Ausstieg prüfen; Zwei-Klick-Platzhalter als <button>, Status per aria-live.

## Umschalter
- Schriftgröße/Dark Mode keine Pflicht. Basis muss ohne stehen (netz-barrierefrei.de). Wenn gebaut: button mit aria-pressed, alles in rem, beide Zustände prüfen.
- Ältere: Basis 18 px, bfit empfiehlt 22 px Textblöcke / 17 px Nebentext, Zeilenabstand 1,5. https://handreichungen.bfit-bund.de/barrierefreie-uie/schrift.html
